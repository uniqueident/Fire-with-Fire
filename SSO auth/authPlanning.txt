MVP IMPLEMENTATION CHECKLIST: CHROME EXTENSION SSO (BARE REQUIREMENTS)
============================================================================
Goal: Minimal viable OAuth 2.0 + PKCE flow to log a user in and get an access token.
============================================================================

1. EXTENSION SETUP (manifest.json)
   - [ ] Add "identity" and "storage" to permissions.
   - [ ] Add your IdP domain to host_permissions (e.g., https://*.your-idp.com/*).
   - [ ] Get your redirect URL via chrome.identity.getRedirectURL() and whitelist it in your IdP dashboard.

2. AUTH CONFIGURATION
   - [ ] Client ID (configured as a Public Client / Single Page App; no secrets).
   - [ ] Authorization endpoint URL.
   - [ ] Token exchange endpoint URL.
   - [ ] Scopes (e.g., "openid email profile").

3. PKCE & CSRF (Bare Security Essentials)
   - [ ] Generate random `code_verifier` (43-128 chars using crypto.getRandomValues).
   - [ ] Generate `code_challenge` (SHA-256 hash of verifier, Base64URL-encoded, method S256).
   - [ ] Generate random `state` (to protect against CSRF / login injection).

4. LOGIN FLOW (chrome.identity)
   - [ ] Build authorization URL with: client_id, redirect_uri, response_type=code, scope, state, code_challenge, code_challenge_method=S256.
   - [ ] Save state & code_verifier in chrome.storage.session.
   - [ ] Launch login window: chrome.identity.launchWebAuthFlow({ url, interactive: true }).
   - [ ] Parse returned callback URL query parameters for `code` and `state`.
   - [ ] Verify returned `state === stored_state` (abort if mismatched).

5. TOKEN EXCHANGE
   - [ ] Send POST request to IdP token endpoint with: grant_type=authorization_code, client_id, redirect_uri, code, and code_verifier.
   - [ ] Receive and parse `access_token` (and ID token / user info).

6. STORAGE & LOGOUT
   - [ ] Save `access_token` and basic user info in chrome.storage.session (or chrome.storage.local).
   - [ ] Check storage when the extension popup opens to determine if user is logged in.
   - [ ] Logout: clear tokens from storage.
