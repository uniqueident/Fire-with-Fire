# Fire-with-Fire

## Setup Instructions

Download Node.Js from [here](https://nodejs.org/en/download)
This will also install npm which will be used to download the next dependencies.

run the following once it is installed:

```
npm install -D vite
```

then run:

```
npx vite
```


**Note** If it fails to run, the problem is likely that you need to go into the directory **before** running the install step.
